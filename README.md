# Legacy Speech Recognition Project

## About

This is a legacy speech recognition project developed around 2013
as part of an academic programming assignment.

The project explores basic techniques used in speech processing
and automatic speech recognition.

The original work was developed using MATLAB/Octave-era tools
and reflects the programming techniques and software libraries
available at that time.

## Main Concepts

The project includes experimentation with:

- WAV audio files
- Frame-based speech processing
- Power Spectral Density (PSD)
- Mel-Frequency Cepstral Coefficients (MFCC)
- Bayesian classification
- Fuzzy C-Means (FCM) clustering
- Gaussian Mixture Models (GMM)
- Confusion matrices

## Processing Pipeline

The general approach can be summarized as:

WAV Audio
→ Frame Processing
→ Feature Extraction
→ FCM Clustering
→ Bayesian Classification
→ GMM
→ Speech Recognition

## Legacy Code

The code is intentionally preserved in its original
legacy form, with only minor cleanup and documentation.

It is **not intended to represent modern MATLAB or Octave
programming practices**.

Some functions used by the original project may be obsolete,
deprecated, or dependent on specific MATLAB/Octave toolboxes
or versions.
